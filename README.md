# Lernprojekt-GitHub

## Ziel
In diesem Projekt lerne ich, wie man mit GitHub Projects arbeitet:
Aufgaben als Issues erstellen, auf einem Kanban-Board organisieren und den Fortschritt verfolgen.

## Struktur
- `src/` – Quellcode
- `docs/` – Dokumentation und Notizen

## Board
Die Aufgaben sind im Project **Lernprojekt-Board** organisiert (To Do, In Progress, Review, Done).
